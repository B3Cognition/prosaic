# Prosaic 0.3.0 — Python cutover

The existing `B3Cognition/prosaic` repository now contains the Python
implementation. Distribution name, import module, and executable are `prosaic`;
there is no production `prosaic-py` rename or Node dependency.

## Upgrade

Use Python 3.11+ with pip, pipx, or uv. Install from the immutable v0.3.0 Git tag
or its GitHub wheel/source assets. This release is not published to npm or PyPI.
The JavaScript library API is retired; use Python snake_case APIs. CLI commands,
configuration filenames/keys, generated bytes, neutral Markdown, camelCase JSON
contracts and ownership manifests retain their existing formats. `prosaic tools`
from 0.2.0 is preserved as read-only discovery; it never executes manifests.

Explicitly remove an old global npm installation only when ready to switch;
check `command -v prosaic` and `prosaic --version` afterward. Existing consumers
with TS/npm installers or old Git pins require a separate installation update.
No consumer pin or global installation is changed by this cutover.

## Verification boundary

The reproducible verifier now freezes TypeScript v0.2.0, commit
`5e0423a289342547d1666db484330ac6adb4743a`. It includes differential/golden Python
tests and 13 original CLI suites, including the tool catalogue, executed through
the Python CLI. Python CI tests 3.11, 3.12 and 3.13 and builds wheel/source assets.
Installed-wheel smoke hides Node from PATH and imports only from site-packages.

Fresh local cutover checks on Python 3.11 passed 432 Python tests and 55 original
CLI tests across 13 suites, including the 0.2.0 catalogue. Frozen current
companions passed 265 Runtime tests at commit
`32555165718b20d3a4ed843725a660cd815ba750` and 107 Harness tests at commit
`580a5475b2a1bd0aa0530931aead9a54d8517e5c` with Python Prosaic selected on PATH.
The installed 0.3.0 wheel passed ten command/workflow smoke checks with Node
hidden, importing from site-packages. The wheel contains only Python production
code and packaged data; the source archive retains development verification
scripts, documentation, tests, and fixtures.

Earlier Runtime/Harness live trials completed staged/preloaded workflows; direct
forced-read requests failed endpoint tool-choice compliance identically with TS
and Python. The Echelon + Codex trial completed requirements authoring, review,
one repair, all eight quality gates and zero-finding terminology validation. It
stopped at the required human approval checkpoint. Design/planning/final
publication, Claude, and delivery are not yet end-to-end verified.

## Safety and rollback

Python intentionally rejects dangling symlink escapes and bounds cyclic package
directory traversal. Other known migration limits and diagnostics are retained
in the historical validation documents. The retired TS implementation, tests,
and build remain recoverable from Git history and v0.2.0. Rollback means selecting
that existing release; it does not require rewriting repository history.

Historical `runs/`, `specs/`, `test-results/`, examples, and conformance fixtures
are retained. Old measurement files describe TS releases, not the Python build.
