## Intentional safety differences

- A dangling symlink whose target lies outside the project is refused before
  creating any file. The frozen reference can follow such a link outside its
  containment boundary.
- Cyclic package-directory symlinks are skipped rather than recursively walked
  forever. Finite files outside the cycle still deploy normally.

Neither difference changes the existing on-disk format. TypeScript retirement,
publication, and permanent consumer dependency changes are separate cutover
steps after candidate acceptance.
